# Spam/Scam Mail Detector 🤖📧⚠️🔗

# Overview ⚠️

1. This program targets the older age group who find it difficult to distinguish bewteen scam/scam mails and normal mails.
2. This program allows the user to input the mail's subject to check if the mail is scam or genuine
3. This program uses a MultinomialNB model that is under supervised learning on a small database
4. 70% of the database is used to train the model and 30% is used to test it, increasing the accuracy.
5. The program also showcases the percentage of accuracy of the model.

# Features 📧

1. This program allows the user to easily input the subject in the terminal.
2. The accuracy percentage of the model is also shown in the output.
3. The model gives a clear output in the terminal showcasing if the mail is spam or not.
4. Without the need of any other app other than a python software, makes it user friendly.

# Technologies Used 💻

1. Pandas is used to slice the data into structured form for the model to read and train
2. A lot of features of sklearn is used to import the blank model and train it.
3. Features like vectorizer is used to convert the data into numerical form to enable the bot to easily learn the data.
4. Feature like accuracy_score is used to showcase the accuracyy percentage of the trained model.

# Steps To Install and Use 💻🤝

1.  Download the main code from the option provided by github
2.  Open the code in any python software (Spyder is recommended)
3.  Make sure the python software is up to date.
4.  Make sure that modules such as pandas and sklearn are already installed and work in the software
5.  If modules are not installed use this command in terminal to download it : pip install pandas scikit-learn
6.  Run the Code and the terminal will start to showcase the accuracy of the model and the area where you can provide the input.
7.  Enjoy!!!
